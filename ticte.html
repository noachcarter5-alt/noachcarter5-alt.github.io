1. 项目概述

TIC项目为一套纯前端静态网页系统，无需后端数据库，依靠浏览器内置 sessionStorage 完成登录状态临时保存，实现多档位权限工作台展示、等级卡片展示、页面跳转功能。整套项目可以部署在GitHub Pages、静态云服务器、本地文件夹直接打开运行。

本系统定位：内部实验人员登记展示平台，一共划分 L1/L2/L3/L4 四个档位，不同档位登录成功后，工作台页面自动展示对应档位文字信息以及档位卡片图片。

本项目全部文件都是静态文件，没有PHP、Java等后台程序，所有登录校验逻辑全部写在前端JS，适合演示、内部实训场景，不可直接用于正式生产涉密环境。

2. 完整文件清单

文件名 类型 作用说明
index.html 网页 TIC项目首页，入口页面，可以跳转登录页
wklogin.html 网页 TIC登录页面，输入账号档位，写入sessionStorage
ticwk.html 网页 TIC员工工作台主页面，档位文字+档位卡片展示，准则、岗位说明、退出登录功能

ticte.html 网页 TIC技术手册页面（当前页），登录后方可查看
IMG_3062.jpeg ~ IMG_3065.jpeg 图片 TIC四个档位对应的身份卡片图片文件

3. 存储规范（sessionStorage）

  • userLevel：保存档位，可选值 L1 / L2 / L3 / L4
  • userAccount：保存登录填写的账号名称
sessionStorage 在关闭浏览器之后自动清空，重新打开浏览器需要再次登录，不会永久保存。

4. 页面跳转逻辑

  1. 访问 ticwk.html，检测无登录信息 → 跳转 wklogin.html
  2. 访问 ticte.html，检测无登录信息 → 跳转 wklogin.html
  3. wklogin登录成功写入sessionStorage，可以选择跳转到工作台或者技术手册ticte.html
  4. 登录成功后，工作台、ticte.html技术手册可以互相来回跳转查看
  5. 点击退出登录，清除sessionStorage，回到登录页面

5. 故障排查清单

  • 打开页面立刻跳登录页：未登录，或者浏览器session被清空
  • 档位图片不显示：图片文件名写错，或者图片没有和html放同一个文件夹
  • 退出登录无效：JS报错，检查logout函数
  • 页面空白：文件损坏，重新复制完整代码
